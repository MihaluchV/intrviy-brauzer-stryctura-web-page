# Інтерв'ю з браузером

Інтерактивний тренажер з інформатики для 11 класу. Модуль «Веб-дизайн», тема «Мова HTML. Структура веб-сторінки. Текстові теги».

## Частини
1. **Інтерв'ю за кодом.** Учень ставить браузеру запитання до рядків коду та обирає його відповідь.
2. **Експерименти «Що, якщо…».** Прогноз поведінки браузера після змін у коді.
3. **Збери структуру сторінки.** Перетягування тегів на потрібні місця.
4. **Підсумок.** Зображення з результатом, кількістю помилок, повернень назад і спроб у частині 3, яке можна зберегти.

## Запуск
Усе в одному файлі `index.html`, без залежностей і збірки. Достатньо відкрити його в браузері.
